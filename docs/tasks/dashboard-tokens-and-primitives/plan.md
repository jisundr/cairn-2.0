# Plan — Track A / Wave 1: tokens & primitives

Design: `docs/features/token-metering-dashboard-ui/DESIGN.md` (full authority — palette, type
scale, elevation/shape rules) + its frozen `mockups/dashboard.html` (concrete reference source —
never edited). Source plan: `docs/features/token-metering-dashboard-ui/plans/01-tokens-and-primitives.md`,
which already resolves font hosting → self-host `.woff2`.

All work lands inside the `token-metering` git submodule. Per `../../features/token-metering-dashboard-ui/GOAL.md`'s
Worktree section, Track A's own worktree (with its own submodule checkout) should exist before
`builder` starts — a prerequisite of this plan, not one of its actionables.

## Scope

- `token-metering/frontend/src/index.css`
- `token-metering/frontend/public/fonts/` (new)
- `token-metering/frontend/src/components/ui/{button,badge,panel,tabs}.tsx`
- `token-metering/static/` (regenerated by `npm run build`, committed per workflow.md, never hand-edited)

Out of scope (scope record): every other component file, `mockups/dashboard.html` itself, backend,
state/routing/api layers.

## Actionables

1. **Source and vendor the three font families** into `token-metering/frontend/public/fonts/` as
   `.woff2`. Vendor only the weights each face actually uses in `DESIGN.md`'s own source
   (`mockups/dashboard.html`'s CSS), not the full set its Google Fonts CDN `<link>` requests (which
   over-fetches unused weights): Big Shoulders 600 + 700 (label), Public Sans 400 + 600 + 700 (body),
   Martian Mono 400 + 600 + 700 (readout). Confirm the vendored Martian Mono file carries tabular
   figures (source plan's explicit ask) — check for a `tnum`/`.tnum` OpenType feature rather than
   relying on `font-variant-numeric: tabular-nums` alone to fake it.

2. **`index.css`** — one commit:
   - Replace all 12 old `:root` custom properties (`--paper`, `--paper-line`, `--ink`, `--ink-soft`,
     `--graphite`, `--block`, `--block-line`, `--window`, `--blue`, `--blue-soft`, `--flag`,
     `--flag-soft`) with `DESIGN.md`'s full scale: `--bone`, `--bone-dim`, `--window`, `--block`,
     `--ink`, `--ink-soft`, `--ink-faint`, `--signal`, `--signal-soft`, `--signal-line`,
     `--ch1`–`--ch4`, `--paper-line`, `--paper-line-soft` (values from `DESIGN.md`'s `colors:`
     frontmatter + its Colors section's Paper Line / Paper Line Soft rgba figures). Note: the new
     `--paper-line`/`--paper-line-soft` reuse two of the old names but carry new rgba hairline
     values — intentional continuity with `DESIGN.md`'s own naming, not a leftover.
   - Add `@font-face` rules for every file vendored in Actionable 1.
   - Add a Tailwind `@theme` block: font-family keys for label/body/readout (`--font-*` namespace,
     matching the Three-Face Rule naming) and a color-token mapping (`--color-*` namespace) for the
     new palette — the two `@theme` additions the scope record's `paths` line calls for. This
     doesn't change how any file *consumes* colors (the whole codebase reads tokens via Tailwind's
     `(--var)` arbitrary-property syntax off `:root` directly, not generated utilities) — it's
     forward infrastructure for later waves, not required by anything this wave touches.
   - Once `--font-label` is registered in `@theme`, Tailwind auto-generates a `.font-label` utility
     itself — delete the hand-rolled `.font-label { font-family: "Space Mono"... }` rule rather than
     leaving two definitions. Every existing consumer of the literal class name `font-label` (14
     files app-wide, only the 4 primitives among them touched this wave) keeps working unchanged:
     same class name, new font stack underneath.
   - Update the `body` rule's `font-family` from Archivo to Public Sans.
   - Verification note for this actionable's own gate: `done_when`'s "no file references `--paper`,
     `--blue`, `--flag`, `--graphite`" means those exact retired tokens (e.g. a `--paper:`
     declaration or `var(--paper)` call) — not a bare substring match, which would also flag the
     intentionally-kept `--paper-line`/`--paper-line-soft`.

3. **Restyle the four `ui/` primitives** — visual only, no prop, callback, or `data-testid` change:
   - `button.tsx`: mockup's `.pill` class is the closest analog (border `--paper-line`, bg
     `--window`, small radius, 600-weight uppercase tracked label-face text) — move off
     `rounded-full`; `DESIGN.md`'s Shapes Don't-rule forbids a pill/fully-rounded radius outside true
     circles.
   - `badge.tsx`: mockup's `.badge` circular counter (border `--ink-soft`, or `--signal-line` for its
     `.flag` variant; **readout/mono face, not label** — it renders a number) is the analog; the
     component's only current consumer (`WarningBanner`'s `{events.length}`) is itself a count.
     Move off the current rectangular label-face pill to a true circle in the readout face — the
     concrete `.badge` class in the frozen mockup is the authority here, more specific than the
     Shapes section's shorter circle-exception list.
   - `panel.tsx`: mockup's `.panel` / `.panel-title` (border `--paper-line`, bg `--window`, `rounded.md`
     radius, title in label face at 700 weight, color `--ink` not `--ink-soft`) — drop `bg-white`
     for `bg-(--window)`.
   - `tabs.tsx`: mockup's `.chart-tabs` (border `--paper-line`, `rounded.sm` radius, label face at
     700 weight; checked segment fills solid `--signal` background with `--window` text — see
     `DESIGN.md`'s own Dial Tabs paragraph) — replace the current blue-border/white-bg checked state
     with the solid signal fill it documents.
   - All four: every `border-(--block-line)` becomes `border-(--paper-line)` (the new scale has one
     hairline border token, not a separate block-line/paper-line split); stay within `DESIGN.md`'s
     documented corner-radius range (1–6px) and font-size ranges per face throughout.

4. **Rebuild and gate**: `npm run build` inside `token-metering/frontend/` (regenerates
   `token-metering/static/` — commit it as its own artifact, never hand-edited, per
   `token-metering/.harness/workflow.md`); `npx playwright test` green with zero assertion changes
   — the two `border-(--blue)` checks in `frontend/e2e/populated/dashboard.spec.ts` (lines 41, 45)
   target `SessionsTable.tsx`, untouched this wave, so they keep matching its unchanged literal
   class name; `pytest test_*.py` inside `token-metering/` as the cheap backend regression check.

5. **Manual visual check** (`npm run dev`, no automated coverage exists for `ui/` primitives today):
   Button (Header's "refresh now"), Badge (WarningBanner's count — seed a usage-limit event to
   trigger it), Panel (any rollup panel), Tabs (TokensPerDayPanel's range tabs). Confirm no
   FOUT/FOIT flash on a hard reload. Expected, not a bug: every other, out-of-scope component
   (Header chrome, EmptyState, SessionsTable, SessionDrilldown, HbarList, TokensPerDayPanel,
   ActivityHeatmap, CallPage, TraceDrawer/TraceDetailContent) will show dangling references to now-
   removed tokens (`--block-line`, `--graphite`, `--blue`, `--blue-soft`, `--flag-soft`, `--paper`)
   until Waves 2–4 land — `ROADMAP.md`'s Wave 1 entry names this "ripple" explicitly; don't edit
   those files to mask it this wave.

6. **Review** — `cairn:reviewer` agent (never `review-pr`) against the diff from Actionables 1–4,
   scoped to this wave.

7. **PR** — opened by the main thread inside the `token-metering` submodule, scoped to Actionables
   1–4's diff only.

## Done when

`npm run build` is clean inside `token-metering/frontend/`; `npx playwright test` is green (zero
test-behavior change); no file under `index.css`, `public/fonts/`, or the four `ui/` primitives
references `--paper`, `--blue`, `--flag`, `--graphite`, `Archivo`, or `Space Mono`.

## Risks

- `badge.tsx`'s reassignment to the mockup's circular/mono `.badge` (rather than keeping its current
  label-face pill shape) is inferred from its sole present consumer being a numeric count — not a
  component `DESIGN.md`'s prose names directly. Re-check this mapping if a later wave gives `Badge`
  a non-numeric call site.
- Removing all 12 old tokens (not just the 4 `done_when` greps) leaves 11 out-of-scope files
  referencing now-undefined custom properties until Waves 2–4 land. Confirmed harmless to this
  wave's Playwright gate (its two token-name assertions check literal class strings, not computed
  style) — worth a second look if a future wave's suite starts asserting computed styles instead.
