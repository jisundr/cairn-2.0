1 Run a normal cairn session — ask for a feature, a fix, anything that dispatches an agent.
2 Let it finish. Capture fires silently when the session ends — nothing to watch for.
3 Come back here, or leave this tab open — it polls automatically once data exists.
Capture is passive and advisory-only — it never blocks or alters a session.
· Dashboard and Sessions are separate tabs, addressed by URL hash (#tab-dashboard / #tab-sessions) so each is linkable/bookmarkable and back/forward works; the usage-limit warning banner's "view session →" link points at the Sessions hash instead of scrolling.
· refresh re-fetches sessions, all six rollups, heatmap, usage-limit events, and projects in one shot; "updated Ns ago" re-ticks every 30s.
· warning banner only renders when the 7-day usage-limit-events endpoint is non-empty, and shows only the most recent event's session id even when the count is higher.
· 7D bar height is max(pct, 2%) so a near-zero day (like today's 254k against a 96M day) still shows a visible sliver instead of vanishing.
· the activity heatmap buckets client-side in the viewer's local timezone, not the server's UTC day/hour.
· most recent session is auto-selected on load and after each refresh, unless the current selection is still present in the range.
· the token-dominant agent auto-expands in the drilldown; every other agent starts collapsed.
· in the Sessions tab, per-call stats (model, tokens, cost, duration) live in the full transcript's turn labels, not a separate table; checking an agent row dims every other agent's turns in place instead of filtering them out.
· the Projects panel, project filter pills, and Project column only appear for a user/local-scope install — a project-scope install only ever captures its own repo.
· a project-scope install names its own repo in the header subtitle instead — there's only ever one project, so the per-session project pill/column would be redundant.
· the tool-calls panel truncates to the top rows with a "+N more" note; the full list isn't paginated in-panel.
· Date-range pills are Today / Daily / Monthly — Daily shows one continuous bar per day (20 days at a glance, click any bar to drill into that day's model breakdown below); Monthly aggregates one bar per calendar month across all recorded history.
